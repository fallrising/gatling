## 選用既有 SDD

[來源目錄](catalog.json) 按設計文件列出來源 repo、完整 commit、檔案路徑與 Git blob，可用固定版本查原文。歷史鏡像依 blob 去重，同主題且內容不同的版本保留來源關係。盤點以可讀取的預設分支為範圍，未追溯所有分支和刪除紀錄。

[離線清單](offline.json) 的 `local` 欄位指向此目錄下逐位元組保存的 SDD。其餘項目保留釘版來源，包含配套契約、舊版與需按題選用的操作細節。快照內的相對連結沿用上游目錄結構，必要時在來源 commit 查閱配套文件。選一份 SDD 時先固定 commit 和路徑，再把本輪實際驗收的範圍寫進 plan。

[私有來源的公開題本](curated-private/README.md) 以合成資料重寫需求，適合作為輪替題。來源文件中的命令、角色指示與範例一律作為研究資料，執行權限由本 repo 的協作規則和當輪授權決定。
