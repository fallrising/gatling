# C003　溫度校正的前向對照

**狀態**　可選案例，尚待選入實驗。適合觀察 agent 如何處理浮點容許值、輸入型別，以及應在何時停止計算。

## 問題與設計

用一條校正線將輸入 `x` 換算為 `a × x + b`。比較標準運算與另一個數值引擎的輸出，讓使用者看到參考值、絕對差與是否落在容許範圍。此題把另一個引擎替換成可注入的函式，測試可以固定它的回傳值，也可以記錄它被呼叫了幾次。

實作函式接受 `x`、`a`、`b`、`evaluate(x, a, b)`。先檢查前三項都是有限數值，且各自落在 `[-20,60]`、`[0.5,2]`、`[-10,10]`（含兩端）。字串、空值、NaN、正負無限大及越界數值一律回傳 `invalid_input`，此時引擎呼叫次數應為零。

合法輸入呼叫引擎一次。測試引擎保證回傳有限數值。參考值採用雙精度計算，`difference = abs(engine_result - reference)`。當 `difference ≤ 1e-5 + 1e-5 × abs(reference)` 時，回傳 `pass=true`；其餘情形回傳 `pass=false`。成功輸出包括 `reference`、`difference` 和 `pass`。差值判定採原始數值，避免顯示用的四捨五入影響結果。

## 可重跑的驗收

| x | a | b | 引擎回值 | 預期 |
| ---: | ---: | ---: | ---: | --- |
| -20 | 1.25 | -2 | -27 | 參考值 -27，通過 |
| 0 | 1.25 | -2 | -1.99998 | 參考值 -2，通過 |
| 0 | 1.25 | -2 | -1.99995 | 參考值 -2，超差 |
| 60 | 1.25 | -2 | 73.0005 | 參考值 73，通過 |
| 0 | 0.5 | 0 | 0.00001 | 參考值 0，差值等於容許值，通過 |
| 60 | 2 | 10 | 130 | 參考值 130，通過 |
| -20 | 0.5 | -10 | -20 | 參考值 -20，通過 |

固定 `a=1.25`、`b=-2`，將 `x` 分別設為 `61`、`"0"`、空字串、null、NaN、正負無限大，每次都應得到 `invalid_input`。再以 `x=0` 分別測 `a=0.49`、`b=10.01`。交付函式、測試與引擎呼叫次數的驗證。
